# Форма настроек интеграции dh-carpet в 1С

Форма и команда создаются только в существующем расширении `ДХКоверИнтеграция`. Конфигурация поставщика не изменяется. Адрес и ключ не хранятся в реквизитах конфигурации или константах: форма передаёт введённые значения серверному модулю `ДХКоверНастройкиСервер`, который записывает их в безопасное хранилище БСП.

## Общая форма

1. Откройте базу в Конфигураторе и выберите `Конфигурация → Расширения конфигурации`.
2. Дважды щёлкните расширение `ДХКоверИнтеграция`.
3. В дереве расширения откройте `Общие → Общие формы`, нажмите `Добавить`.
4. Укажите имя `ДХКоверНастройкиИнтеграции`, синоним `Настройки интеграции dh-carpet`.
5. Откройте форму и создайте два реквизита формы, не связанных с объектами конфигурации:

| Имя | Тип | Длина |
|---|---|---:|
| `АдресСервера` | `Строка` | 1024 |
| `КлючAPI` | `Строка` | 512 |

6. Перетащите оба реквизита в группу `Элементы` формы, чтобы появились два поля ввода.
7. Для поля `АдресСервера` задайте заголовок `Адрес сервера`.
8. Для поля `КлючAPI` задайте заголовок `Ключ API` и свойство `Режим пароля` (`РежимПароля`) — `Да`.
9. Не включайте сохранение значений полей в пользовательских настройках и не связывайте реквизиты формы с константами, реквизитами конфигурации или хранилищем общих настроек.
10. В узле `Команды` формы добавьте команду `Сохранить` с заголовком `Сохранить`.
11. Перетащите команду `Сохранить` на командную панель формы.
12. Для действия команды выберите создание клиентского обработчика `Сохранить`.
13. Откройте модуль формы, удалите созданную пустую процедуру, если она есть, и целиком вставьте `integrations/1c/SettingsFormModule.bsl`.

После успешного вызова сервера форма показывает `Настройки сохранены` и присваивает полю `КлючAPI` пустую строку. При ошибке сохранения поле не очищается, чтобы администратор мог исправить адрес или повторить попытку.

## Общая команда открытия

1. В дереве расширения откройте `Общие → Общие команды`, нажмите `Добавить`.
2. Укажите имя `ДХКоверОткрытьНастройкиИнтеграции`.
3. Укажите синоним `Настройки интеграции dh-carpet`.
4. Поле `Тип параметра команды` оставьте пустым.
5. Свойство `Группа` установите в `Панель навигации.Обычное`.
6. Свойство `Изменяет данные` установите в `Да`.
7. Откройте модуль команды и целиком вставьте `integrations/1c/SettingsOpenCommand.bsl`.

## Размещение в разделе «Администрирование»

Техническое имя административной подсистемы зависит от конфигурации поставщика, поэтому его нельзя задавать наугад. Используйте существующую подсистему, у которой в свойствах указан синоним `Администрирование` и которая соответствует одноимённому разделу запущенного приложения.

1. В основном дереве конфигурации откройте `Общие → Подсистемы` и найдите подсистему с синонимом `Администрирование`.
2. Вызовите её контекстное меню и выберите `Добавить в расширение`, затем укажите `ДХКоверИнтеграция`. Это заимствует объект в расширение, но не изменяет конфигурацию поставщика.
3. В дереве расширения откройте добавленную подсистему и нажмите `Состав`.
4. В составе отметьте `Общие команды → ДХКоверОткрытьНастройкиИнтеграции`.
5. Вызовите для этой подсистемы `Командный интерфейс`.
6. Найдите команду `Настройки интеграции dh-carpet` в группе `Панель навигации → Обычное` и включите её видимость. Если редактор показывает колонки ролей, оставьте команду видимой как минимум для административной роли, под которой выполняется настройка.
7. Выполните `Конфигурация → Проверка конфигурации`.
8. Сохраните расширение и выполните `Конфигурация → Обновить конфигурацию базы данных`.
9. Перезапустите сеанс `1С:Предприятие`.
10. Откройте раздел `Администрирование` и выберите `Настройки интеграции dh-carpet` в панели навигации.

Если в приложении нет раздела с синонимом `Администрирование`, выполните те же действия с существующей подсистемой, в которой размещены системные настройки. Выбранный раздел будет точным местом появления команды в `1С:Предприятии`; техническое имя не следует придумывать без просмотра реальной конфигурации.

## Первичная настройка

1. В поле `Адрес сервера` введите доступный серверу 1С адрес с обязательной схемой `http://` или `https://`. Допускаются явный порт и базовый путь.
2. В поле `Ключ API` введите production API key. Не вставляйте его в исходный код, Конфигуратор, константу или Git.
3. Нажмите `Сохранить`.
4. Убедитесь, что появилось сообщение `Настройки сохранены`, а поле ключа очистилось.
