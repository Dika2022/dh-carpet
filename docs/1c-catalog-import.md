# Первичный импорт каталога из 1С

Backend уже принимает полный каталог в массиве `rugs` запроса `POST /api/internal/1c/bulk` с `mode=initial`. Barcode остаётся главным business ID. UUID ссылки `Справочник.Номенклатура` должен передаваться в `raw_payload.nomenclature_uuid`; отдельная колонка и миграция для этого не требуются, потому что исходный snapshot сохраняется версионно в PostgreSQL.

В импорт входят только элементы из групп `Ковры`, `Ковролины`, `Ковролины (в т.ч. дорожки)`, `Шкуры` и их подгрупп. Группы и помеченные на удаление элементы исключаются. Нулевой остаток не исключает товар. В `retail_price` разрешена только цена вида `Розничная цена`; закупочные и прорабские цены передавать запрещено. Продажи и возвраты не создают отсутствующий ковёр автоматически.

## Текущая граница реализации

Подтверждены справочник `Справочник.Номенклатура`, его основные поля и имена регистров `РегистрНакопления.Запасы` и `РегистрСведений.ЦеныНоменклатуры`. Для корректного BSL-адаптера ещё нужны точные имена:

- измерения номенклатуры и ресурса количества регистра `Запасы`;
- измерений склада, ячейки и единицы регистра `Запасы`, если они существуют;
- измерения номенклатуры, измерения вида цены и ресурса цены регистра `ЦеныНоменклатуры`;
- metadata name справочника вида цены, периодичность регистра цен, поля единицы и валюты, если они существуют.

До подтверждения этих имён полноценный `CatalogAdapter.bsl` намеренно не создаётся: нулевое значение нельзя использовать вместо неизвестного остатка, а произвольную цену нельзя считать розничной.

## Один запуск диагностики

1. В Конфигураторе откройте ранее использованную временную внешнюю обработку metadata discovery или создайте пустую внешнюю обработку.
2. Создайте управляемую форму, строковый реквизит `РезультатДиагностики` неограниченной длины и команду `ВыполнитьДиагностику`.
3. Поместите реквизит и кнопку команды на форму.
4. Замените модуль формы содержимым `integrations/1c/CatalogMetadataDiscovery.bsl`.
5. Сохраните `.epf`, откройте её в 1С:Предприятии и нажмите `Выполнить диагностику`.
6. Скопируйте целиком JSON из `РезультатДиагностики` и передайте его разработчику.

Диагностика только читает metadata и не более 50 групп с четырьмя точными наименованиями. Товары, документы и регистры она не изменяет и весь каталог не перебирает.
