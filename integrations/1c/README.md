# Интеграция dh-carpet с 1С

Это отдельная интеграция; старая обработка `shop.dinastyhan.ru` не изменяется. Транспорт: 1С формирует JSON и отправляет HTTPS POST в `/api/internal/1c/bulk` с заголовком `X-Internal-API-Key`. Ключ хранится вне исходников 1С и Git.

Подтверждены только `Справочник.Номенклатура`, его перечисленные в проектной документации поля, `РегистрНакопления.Запасы.Остатки`, `РегистрСведений.ЦеныНоменклатуры` и вид цен с наименованием `Розничная цена`. Файл `Transport.bsl` не зависит от метаданных прикладных документов. `CatalogExport.bsl` содержит запрос только к подтверждённым полям номенклатуры.

`MetadataDiscovery.bsl` предназначен для диагностического запуска в реальной базе. До анализа его результата адаптеры продаж и возвратов намеренно не созданы: технические имена документов, табличных частей и полей нельзя определять по пользовательским представлениям.

Расширение должно самостоятельно проверять отдельное право просмотра истории перед запросом history/graph API. Подтверждение и отклонение цен Лалиты из 1С не реализуются: это административная операция dh-carpet.
