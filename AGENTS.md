# Правила работы с репозиторием

## Язык и процесс разработки

- Основной язык документации и комментариев проекта — русский, если нет технической причины использовать английский.
- Разработка ведётся только в локальном Git-репозитории.
- Весь исходный код и документация проекта должны поддерживаться через Git.
- Изменения доставляются через Git/GitHub и штатный процесс развёртывания.
- Production-сервер не используется для ручного редактирования исходного кода или документации.

## Безопасность и данные

- Секреты, файлы `.env`, пароли, токены и ключи запрещено коммитить в Git.
- PostgreSQL является основной базой данных и источником истины для данных приложения.
- Redis используется для очередей и временных данных.
- Qdrant используется как производный векторный индекс и не является источником истины.
- Напрямую читать внутренние SQL-таблицы базы 1С запрещено. Интеграция с 1С должна выполняться через предусмотренный интерфейс, агент или расширение.
- Изменения структуры PostgreSQL должны выполняться через миграции.
- Необратимые операции с production-данными запрещено выполнять без явного подтверждения.
